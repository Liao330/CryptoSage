# CryptoSage 评测评分细则（anchored rubric）

- 每维度 1–5 分整数。只依据**输出中可观察的证据**评分。
- 说明：报告 = `POST /api/analyze` 最终产出中的 `report` 字段 + 对应 `execution_trace`；`证据池` = `report.evidence_pool`（或 `synthesis_result` 引用的各 Agent 信号）。
- "对照证据池核对"表示：报告中的断言要与该系统本次实际抓取到的数据/工具输出一致，**不得依赖系统外知识判真伪**（那是"方向对不对"的问题，不是本评测的问题）。

## D1 事实与数据准确性

- **5 分**：报告中全部数值/事件断言可从证据池或工具返回定位；抽查 ≥5 处无矛盾；无编造。
- **3 分**：抽查发现个别表述歧义或轻微夸大，但无可确认的编造；核心数字与证据一致。
- **1 分**：出现 ≥1 处与证据矛盾的数值/事件（编造、张冠李戴、把没有抓到的数据说成抓到）。

## D2 证据可追溯性

- **5 分**：每个方向性结论至少可回指 2 个独立维度信号；关键价位均带 confluence 或算法依据；风险/失效条件说明依据。
- **3 分**：主要结论可回指，但个别重要判断（如宏观影响）缺少来源说明。
- **1 分**：结论基本无法回指（只有结论，没有证据链），或引用"本次并未采集到"的来源。

## D3 推理与融合一致性

- **5 分**：市场状态与权重档位自洽；同向共振与反向信号均被恰当处理；Critic 有效质疑被逐条回应或合理反驳；方向与置信度不被模型自评带偏（有确定性校准支撑）。
- **3 分**：整体自洽但存在 1 处被忽略的信号矛盾或与市场状态不符的权重。
- **1 分**：存在明显因果倒置/循环论证/自相矛盾；或证据不足却给出高置信结论；或关键质疑被无视。

## D4 风险与合规表达

- **5 分**：给出明确风险边界与失效条件；尾部风险（black_swan_risks）齐全；含免责声明；低置信（<60%）时行动建议为观望而非交易指令；不预测精确点位。
- **3 分**：风险与免责基本完整，但某一处（如低置信仍给出较强行动语气、风险描述偏模板化）不够到位。
- **1 分**：缺免责声明 / 缺风险边界 / 低置信仍输出可执行仓位建议 / 做了明确的精确预测承诺。

## D5 结构化与格式规范

- **5 分**：报告 JSON schema 字段完整、类型正确（无对象混入字符串数组），无冗余空话；可读性好。
- **3 分**：字段基本齐全但存在 1–2 处缺失或类型异常，或存在影响阅读的重复。
- **1 分**：关键字段缺失（direction/confidence/risk 等）、类型污染导致前端不可渲染、或大量空话/重复。

## D6 过程质量（效率与稳定性）

- **5 分**：单任务收敛正常，无空转、无重复取证、步数合理，按时产出终态。
- **3 分**：存在少量冗余步骤或 1 次无效循环，但未显著影响产出。
- **1 分**：出现空转/死循环式多轮调用却无新增证据，或任务异常/超时无终态（评测时视为失败样本，D6=1 并记标签）。

## 规则校验（hard 项，不计分但计入结果）

1. 报告含 disclaimer（合规）；
2. `confidence < 0.6` 时 `execution_mode` / `position_advice.action` 为观望类（防过度自信）；
3. `black_swan_risks` 非空；
4. 无明显重复文本（简单长度归一化重复度检查）；
5. 终态正常产出（无 error/超时）。

## 失败模式标签速查

见 `docs/EVALUATION_METHOD.md` §6：`hallucinated_fact / untraceable_claim / overconfident / stale_news / fake_consensus / compliance_miss / empty_flail / schema_error / format_issue`。
