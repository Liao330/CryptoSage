# Demo 视频 / GIF 说明

> 实战任务要求：提供**时长 2 分钟以内**的 demo 视频或 GIF，展示应用端到端可用性。

## 覆盖要求（建议 ≥2 个端到端流程）

1. **完整多 Agent 研判**
   - 输入："分析 BTC 当前是否适合进场"
   - 展示：Orchestrator 规划 → 5 个专家并行取证（技术/链上/衍生品/舆情/宏观）→ Synthesis 融合 → Critic 对抗 → 最终研判报告（方向/置信度/关键价位/风险边界）
   - 加分点：展示模型慢思考过程（前端可折叠"模型思考"）与工具调用轨迹。

2. **事件驱动快速分析**
   - 输入："ETH 刚才突然大跌，发生了什么？"
   - 展示：衍生品（爆仓/资金费率）+ 链上 + 宏观新闻联动，以及新闻时效守卫/事件图谱可视化。

## 放置约定

- 文件名：`docs/demos/demo1_bullish_analysis.gif`、`docs/demos/demo2_event_driven.gif`（或对应 .mp4）；
- 本仓库 `.gitignore` 默认忽略媒体大文件，但已放行 `docs/demos/` 下的 GIF/MP4，可直接入库；若文件过大，建议压缩到 2min / 5MB 内，或用 GitHub Releases 存放后在 README 附链接；
- 录制建议：`frontend` dev 模式（`npm run dev`）+ 后端 `python -m backend.main`，录制窗口分辨率 1280×800 即可，突出"过程可视化 + 最终报告"两个看点。

## 录制清单（录制前勾选）

- [ ] 系统能正常完成一次完整分析并出报告
- [ ] 事件流实时可见（Agent 过程 / 思考折叠项）
- [ ] 报告字段齐全（含免责声明与风险边界）
- [ ] 总时长 ≤2 分钟，关键画面节奏清晰
- [ ] 将成品放入本目录并在根 README「Demo」小节补链接
