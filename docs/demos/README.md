# Demo 视频 / GIF 说明

> 实战任务要求：提供**时长 2 分钟以内**的 demo 视频或 GIF，展示应用端到端可用性。

## 覆盖要求（建议 ≥2 个端到端流程）

1. **完整多 Agent 研判**
   - 输入："分析 BTC 当前是否适合进场"
   - 展示：Orchestrator 规划 → 5 个专家并行取证（技术/链上/衍生品/舆情/宏观）→ Synthesis 融合 → Critic 对抗 → 最终研判报告（方向/置信度/关键价位/风险边界）
   - 加分点：展示模型慢思考过程（前端可折叠"模型思考"）与工具调用轨迹。

2. **事件驱动快速分析**
   - 输入："ETH 刚才突然大跌，发生了什么？"
   - 展示：衍生品（爆仓/资金费率）+ 链上 + 宏观新闻联动，以及新闻时效守卫/事件图谱可视化。
