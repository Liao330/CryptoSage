# 评估方法有效性验证（VALIDATION）

> 按实战任务要求，至少完成两项验证：**判别力验证** 与 **一致性验证**。本文档记录实验设计与过程数据，待评测运行后回填结果。此处的目标是"证明评估方法本身可靠"，而非评测系统表现。

---

## 1. 判别力验证（能否区分质量明显不同的输出）

### 1.1 实验设计

对同一批样本（≥10 条），构造质量明显不同的三档输出：

| 档位 | 构造方式 | 预期 |
|---|---|---|
| 好（G） | 系统真实运行产出（完整五维证据 + 融合 + 对抗） | 得分显著最高 |
| 中（M） | 截断证据池（只保留 1 个维度）、移除 Critic 对抗轮、提示"简单给结论" | 得分居中 |
| 差（B） | 规则性构造坏输出：加入编造价位、去掉免责声明与风险字段、重复空话 | 得分显著最低 |

> 中/差档通过修改输入证据或对报告做受控改写生成，**不改变样本自身难度**，确保差异只来自输出质量。

### 1.2 判定指标

- G/M/B 三组总分均值是否**严格单调**（G>M>B）；
- 组间差异是否显著（因样本相关，使用配对符号检验或 Wilcoxon 符号秩检验）；
- 维度级判别的稳定性：哪些维度最易区分、哪些维度区分力弱（弱区分维度将修订锚点）。

### 1.4 对抗性补充（鼓励项）

## 2. 一致性验证（评估结果与人工一致 / 多次评分波动）

### 2.1 与人工标注的一致性

- 抽样 10–15 条输出，由人工按同一 rubric 打分（标注口径见 `evaluation/rubric.md`），与 LLM-as-judge 结果对比；
- 指标：维度级与总分级的**一致性 / 相关性**（如 Cohen's κ 或 Spearman 相关）、系统性格差（judge 是否系统性偏高/偏低）；
- 判定：总分相关 ≥ 0.7 视为基本可靠，否则调整 rubric 措辞或补 judge 示例（few-shot）。

### 2.2 多次评分波动（judge 稳定性）

- 同一输出重复评测 3 次（temperature=0），统计各维度得分波动；
- 指标：标准差与"翻转区间"（同一维度 1↔3 级别的跳变率）；
- 另统计**双 judge 分歧率**（分歧 >1 分需仲裁的样本占比），分歧率高即说明该维度锚点不锐利。
